# Prompts da identidade visual do MeuTreino

Modo utilizado: ImageGen integrado, com geração do ícone, geração do símbolo de abertura e uma edição do símbolo.

## Ícone do aplicativo

```text
Use case: logo-brand
Asset type: production iOS app icon for the fitness app MeuTreino
Primary request: create one original, bold, minimal symbol that combines a compact dumbbell with a subtle upward energy/check gesture, communicating strength and completed workouts
Style/medium: flat vector-like logo mark rendered as a crisp square raster icon
Composition/framing: centered geometric mark, strong silhouette, generous optical padding, designed to remain recognizable at 29 px
Color palette: vivid lime green #A6F033 full-bleed background with near-black #0E1115 symbol; optional tiny off-white highlight only if essential
Constraints: exactly square 1024x1024 composition; background fills every corner; no transparency; no rounded corners baked into the image; no text; no letters; no gradients; no 3D; no mockup; no shadows outside the mark; no watermark; original design only
Avoid: generic stock fitness badge, overly detailed weights, thin lines, photographic elements
```

## Símbolo da tela de abertura

```text
Use case: logo-brand
Asset type: transparent splash-screen mark for the iOS fitness app MeuTreino
Primary request: create a single compact geometric symbol combining a dumbbell and a clear check/upward energy gesture, visually consistent with a modern workout tracker
Style/medium: flat vector-like logo mark rendered as a crisp raster cutout
Composition/framing: centered symbol with balanced proportions and generous transparent padding; strong silhouette legible when shown around 110 px wide
Color palette: vivid lime green #A6F033 only
Constraints: genuinely transparent background with preserved alpha; no text; no letters; no enclosing square or circle; no gradient; no 3D; no shadows; no mockup; no watermark; original design only
Avoid: thin lines, tiny details, photographic elements, extra objects
```

## Edição final do símbolo

```text
Use case: precise-object-edit
Asset type: transparent iOS splash-screen logo mark
Primary request: remove only the neon glow, blur, haze, and any gradient from the existing lime dumbbell/check symbol; make the mark a single crisp flat solid color #A6F033
Constraints: preserve the exact symbol geometry, proportions, framing, and genuinely transparent background; keep every background pixel transparent; no text; no shadow; no glow; no gradient; no extra elements; no watermark
```
