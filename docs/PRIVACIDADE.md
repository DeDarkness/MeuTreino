## 1. Visão geral

O MeuTreino é um aplicativo para criação e registro de treinos. Ele pode ser usado localmente, sem conta, ou com uma conta opcional para sincronização entre o aplicativo no iPhone e o editor web.

## 2. Dados tratados no modo local

Sem uma conta, fichas, exercícios, séries, repetições, cargas, descansos, observações, preferências e histórico ficam armazenados no próprio aparelho. Esses dados não são enviados ao servidor de sincronização.

## 3. Dados tratados ao usar a sincronização

Quando a pessoa escolhe criar uma conta, o MeuTreino trata:

- endereço de e-mail e identificador interno da conta;
- fichas, exercícios, séries, repetições, cargas e tempos de descanso;
- histórico, preferências, nomes e observações adicionados pela pessoa.

Esses dados são usados somente para autenticar a conta, manter o funcionamento do serviço e sincronizar as informações entre os aparelhos da própria pessoa.

## 4. Prestador de serviço

O Supabase é usado como prestador de autenticação, banco de dados e sincronização. Ele processa dados em nome do responsável pelo MeuTreino para fornecer essas funções. O MeuTreino exige que prestadores aplicáveis protejam os dados de modo compatível com esta política e com as obrigações legais pertinentes.

## 5. Venda, anúncios e rastreamento

O MeuTreino não vende dados pessoais, não exibe anúncios e não usa os dados de treino para rastrear pessoas em outros aplicativos ou sites.

## 6. Retenção e exclusão

Os dados locais permanecem no aparelho até serem apagados no app, até a conta ser excluída ou até os dados do aplicativo serem removidos do aparelho. Os dados sincronizados permanecem enquanto a conta estiver ativa.

Uma pessoa conectada pode abrir **Conta > Excluir minha conta** no aplicativo. Após a confirmação, a conta e os dados associados são removidos permanentemente. Informações só serão mantidas quando houver uma obrigação legal aplicável, caso em que o motivo e o prazo deverão ser informados.

## 7. Segurança

O acesso à sincronização exige autenticação. As regras do banco restringem cada conta aos próprios dados. Embora sejam adotadas medidas técnicas e organizacionais apropriadas, nenhum sistema conectado à internet elimina todos os riscos.
